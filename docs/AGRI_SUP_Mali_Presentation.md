# AGRI'SUP Mali — Présentation de l'établissement

> **Important :** cette fiche rassemble les informations recueillies pour préparer le projet. Elle ne remplace pas une présentation institutionnelle officiellement validée. Toute information sensible ou susceptible d'avoir changé doit être confirmée avant publication.

---

# 1. Identité

## Nom

**AGRI'SUP**

## Dénomination

**École Supérieure Privée des Sciences et Technologies Agricoles**

## Pays

**Mali**

## Nature

Établissement privé d'enseignement supérieur spécialisé dans les sciences et technologies agricoles.

## Localisation actuelle

**Sotuba ACI, Bamako, Mali**

---

# 2. Positionnement

AGRI'SUP se positionne dans le domaine de l'enseignement supérieur agricole.

Son champ couvre notamment les sciences et technologies liées à :

- l'agriculture ;
- l'élevage ;
- la production animale ;
- l'aquaculture ;
- d'autres domaines liés aux sciences agricoles.

> La liste définitive des domaines doit être confirmée par AGRI'SUP.

---

# 3. Historique

Les informations recueillies indiquent qu'AGRI'SUP possède des origines à **Ségou** et que son activité a évolué progressivement vers l'enseignement supérieur.

Une date de **2006** apparaît dans les informations disponibles comme repère historique.

L'établissement est aujourd'hui associé à une implantation à **Sotuba ACI, Bamako**.

## À confirmer

Avant publication officielle, il faut valider :

- l'année exacte de création ;
- le lieu de création ;
- les différentes étapes de l'évolution ;
- la date d'installation à Bamako ;
- les changements de dénomination éventuels ;
- l'évolution des formations.

# 17. Informations à ne pas inventer

Pour un site institutionnel, ne jamais inventer :

- nombre d'étudiants ;
- nombre d'enseignants ;
- taux d'insertion ;
- taux de réussite ;
- classement ;
- accréditation ;
- partenariat ;
- frais ;
- diplôme ;
- durée ;
- infrastructures ;
- chiffres clés.

Si une information n'est pas confirmée, elle doit être :

- vérifiée ;
- retirée ;
- ou explicitement indiquée comme information à confirmer dans les documents internes.

# 21. Résumé institutionnel

**AGRI'SUP — École Supérieure Privée des Sciences et Technologies Agricoles** est un établissement privé d'enseignement supérieur malien orienté vers les sciences et technologies agricoles.

Les informations actuellement disponibles situent l'établissement à **Sotuba ACI, Bamako**, avec des origines mentionnées à **Ségou** et une évolution vers l'enseignement supérieur.

Les formations mentionnées comprennent notamment des **DUT** et des **Licences professionnelles**, dans différents domaines liés aux sciences agricoles.

Le positionnement à mettre en avant pour le site est celui d'une institution spécialisée dans la formation agricole et la professionnalisation, sous réserve de validation des formulations et données officielles.
